Rocket Focus

I created this web for people who need to concentrate and be productive, also for fun and learning.

It consists on a basic timer (like a pomodoro timer) that allows the user to set it depending on the needs of the user. 
The user can set the time he wants and while he is doing his activity, the rocket which is on the web will be travelling.
While the timer is on, space-music will be playing, but when the time runs out the rocket will reach the moon (which will be shine)
and a random (and funny) alarm will advert the user than his productivity time has finished.
